# 每日大模型新闻采集

## 目标
每天（默认 09:00 由外部调度触发）从网络媒体搜集 5 条大模型相关新闻，
整理后写入 `news/YYYY-MM-DD-llm-news.txt`。

## 前置说明：定时由谁负责
本 Skill 只定义「怎么做」，不含「何时做」。09:00 的定时由宿主调度器负责：
- 若宿主支持定时任务：把触发时间设为每天 09:00，触发后加载本 Skill 执行。
- 若为手动执行：直接以「今天」作为目标日期跑一次即可。

## 步骤

### 1. 确定目标日期
调用 current_time 获取当天日期（YYYY-MM-DD）。若用户显式指定日期，以用户指定为准。

### 2. 搜索新闻
用 web_search 检索，覆盖中文与英文来源。建议至少执行以下查询（可增减）：
- 大模型 最新新闻
- AI 大模型 今日发布
- LLM news today
- OpenAI Anthropic DeepMind 最新

优先媒体源见 references/sources.md。多搜几轮，目标收集 15~25 条候选。

### 3. 筛选与去重
- 对同一事件去重，只保留一条。
- 仅保留与大模型/基础模型直接相关的内容（模型发布、版本更新、融资、政策监管、评测榜单、开源等）。
- 按重要性与时效性排序，选出前 5 条。若不足 5 条，如实说明并输出已有的条数。

### 4. 整理为结构化 JSON
每条须含：title, source, time, summary, url。示例：
[{"title":"...","source":"...","time":"2026-09-28","summary":"...","url":"https://..."}]

### 5. 写入文件（执行脚本）
把上一步的 JSON 通过 stdin 传给脚本执行：
    echo '<JSON>' | python scripts/save_news.py --date 2026-09-28 --outdir news
脚本会打印实际写入路径，形如 news/2026-09-28-llm-news.txt。

### 6. 校验并回报
- 确认文件已生成，且包含 5 条。
- 向用户回报：文件路径 + 5 条标题清单。

## 约定
- 文件名统一为 YYYY-MM-DD-llm-news.txt，统一放在 news/ 目录下。
- 默认覆盖同日文件；需保留历史可自行调整脚本。
- 摘要必须原创改写，不得整段照抄；保留原文链接。
