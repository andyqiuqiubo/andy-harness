# 概念讲解

把一个概念、技术或术语，讲得让目标听众真正听懂——而不是复述教科书定义。

## 何时使用
- 用户询问「什么是 X」「X 是怎么工作的」「帮我理解 X」。
- 用户希望用大白话或给特定受众（初学者 / 孩子 / 非技术人员）解释。

## 步骤
1. **锁定受众与深度**：先判断用户的知识水平（必要时简短确认）。初学者要少术语、多类比；进阶者可直接讲机制。
2. **给出一句话直觉**：先用一句最朴实的话概括「它到底是什么 / 解决什么问题」。
3. **展开讲解**，按：
   - 它解决什么问题 / 为什么存在
   - 核心机制（用类比降低门槛，例如把「缓存」比作「书桌上的常用文具」）
   - 一个最小例子或场景
   - 与其他相近概念的区别（如有）
4. **收尾**：一句总结 + 一句「什么时候会用到它」。
5. 用**用户提问的语言**输出（中文提问→中文讲解）。

## 示例结构
```
一句话：<最朴素的解释>

为什么需要它：<问题/动机>

打个比方：<生活化类比>

怎么工作的：<核心机制，尽量直观>

一个小例子：<场景>

和 X 的区别：<对比，可选>

小结：<一句话 + 使用时机>
```

## 注意事项
- 类比要准确，不为了通俗而牺牲正确性。
- 不堆砌术语；每引入一个新术语，要用前述方式再解释一次。
