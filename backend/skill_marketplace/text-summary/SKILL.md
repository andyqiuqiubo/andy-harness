# 长文摘要

把冗长的文本（文章、报告、文档、对话）提炼成结构化、可扫读的摘要，去芜存菁。

## 何时使用
- 用户提供长文，希望「总结」「提炼要点」「给个摘要」。
- 用户给出链接或文档，需要先抓住核心再决定是否深读。

## 步骤
1. **识别文本类型与长度**，决定摘要粒度：短文→几句话；长文→分层摘要。
2. **提取骨架**：
   - 核心结论 / 主旨（最重要，放最前）
   - 关键论点或章节要点
   - 重要数据、数字、日期（原文照搬，确保准确）
   - 作者态度 / 未解决的问题（如适用）
3. **结构化输出**：

```
# 摘要：<原文标题或主题>
## 一句话结论
<最核心的那句话>

## 关键要点
- …

## 重要数据
- <数字/事实，附上下文>

## 值得注意
- <例外、争议、未决项>
```

4. **压缩比控制**：摘要长度约为原文的 10%–20%；纯事实型可更短，论述型保留逻辑链。
5. 用**用户提问的语言**输出（中文提问→中文摘要）。

## 注意事项
- 不歪曲原意、不添加原文没有的观点。
- 数字、专有名词、结论必须忠实于原文；拿不准的标注「原文称」。
- 若原文冗长且主题分散，先给全局摘要，再问用户是否需要某部分深入。
