# 多语种翻译与润色

在中文、英文、日文等自然语言之间翻译文本，并按场景做本地化润色（而非机械直译）。

## 何时使用
- 用户给出外文，想知道意思或要翻译。
- 用户要求「翻译成英文/日文」「这段话润色得更地道」。

## 步骤
1. **确认目标语言与目的**：译入哪种语言？用途是正式文档、口语、代码注释还是 UI 文案？语气如何？（信息不足时简短确认）
2. **翻译**，遵循：
   - 意译优先于逐字直译，符合目标语言习惯。
   - 保留专有名词、代码、命令、产品名原文（除非约定俗成有译名）。
   - 数字、单位、日期按目标语言惯例呈现。
3. **本地化润色**：根据场景调整措辞，使译文读起来像母语者所写。
4. **多义提示**：若原文有歧义或一词多义，给出主译并附「也可理解为…」。
5. 输出用**目标语言**；若用户仅要求「解释意思」，用**用户提问的语言**说明。

## 输出格式
```
【译文】
<翻译后的文本>

【说明（可选）】
- 术语/歧义提示
- 润色依据
```

## 注意事项
- 不凭空增删事实；技术内容保持准确。
- 涉及文化敏感或双关时，说明直译与意译的差异，让用户取舍。
