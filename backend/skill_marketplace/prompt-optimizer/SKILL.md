# 提示词优化

把一句模糊的需求，改写成**角色清晰、约束明确、输出可控**的提示词，提升模型一次到位的概率。

## 何时使用
- 用户想为某个任务写/改提示词（写作、分析、代码、客服、抽取等）。
- 用户反馈「模型答非所问」「输出格式不对」「太啰嗦」。
- 需要把通用指令适配到具体场景。

## 步骤
1. **定位任务**：弄清用户要模型「做什么」、面向谁、期望什么形态的输出。
2. **补齐四要素**：
   - **角色 / 背景**：你是谁、面向什么场景。
   - **任务**：具体要完成什么，含输入是什么。
   - **约束**：语气、长度、禁忌、必须包含/排除的内容。
   - **输出格式**：JSON / 表格 / 分点 / 固定模板。
3. **消除歧义**：把「好一点」「相关材料」这类词换成可执行的明确描述。
4. **给成品**：输出可直接复制的优化版，并附 1–2 个变体（如「宽松版 / 严格版」）。
5. **提示技巧**：
   - 复杂任务用「先思考再回答」或分步指令。
   - 需要稳定结构时显式写出格式模板。
   - 易跑偏时加「只输出…不要解释」类护栏。

## 注意事项
- 不要过度堆砌约束导致模型束手束脚；只保留关键约束。
- 区分「用户想做的任务」和「写给模型的提示词」，前者是输入、后者是产出。
- 涉及敏感/隐私数据时，提醒用户不要在提示词里硬编码密钥或个人识别信息。
