# 邮件 / 消息起草

把用户的零散要点、背景或口述，转化为结构清晰、语气得体的邮件或工作消息。

## 何时使用
- 用户要求写邮件、消息、通知、公告。
- 用户提供要点，希望扩写成正式文本。

## 步骤
1. **澄清语境**（若信息不足，先简要确认，不要凭空编造关键事实）：
   - 收件人关系（上级 / 同事 / 客户 / 下属）
   - 目的（告知 / 请求 / 致歉 / 催促 / 汇报）
   - 需要的语气（正式 / 中性 / 亲切）
   - 是否要包含附件或后续动作
2. **组织内容**：开场（背景/目的）→ 正文（要点分条）→ 结尾（诉求/下一步/署名）。
3. **起草**，遵循：
   - 主题行：一句话概括，便于扫读。
   - 正文：多用短句与列表，避免大段文字。
   - 行动诉求明确：谁、做什么、何时。
4. **自检**：是否达成了用户的目的？是否有歧义或遗漏？语气是否与收件人匹配？
5. 用**用户提问的语言**输出（中文提问→中文邮件）。

## 输出格式
```
主题：<一句话主题>

<称呼>，

<正文>

<落款/署名，如适用>
```

## 注意事项
- 不替用户编造虚假事实、数据或承诺。
- 涉及敏感或承诺性内容时，提醒用户核对关键信息再发送。
