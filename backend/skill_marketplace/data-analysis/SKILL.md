# 数据文件分析

把用户给的数据（CSV、Excel、或粘贴的表格）变成**可行动的结论**：先确认字段含义与口径，再做统计与对比，最后用图表建议和关键数字说话。

## 何时使用
- 用户上传或贴出结构化数据，希望「分析一下」「找规律」「看异常」。
- 需要描述统计、分组聚合、时间序列趋势、相关性或简单的对比。
- 需要决定「该画什么图」来呈现结论。

## 步骤
1. **理解数据**：先读表头、行数、字段类型；向用户确认模糊字段的含义与单位（不要擅自假设）。
2. **清洗提示**：指出缺失值、重复行、明显异常值；必要时说明处理方式（删除 / 填充 / 保留）。
3. **描述统计**：对数值列给均值、中位数、极值、分布形态；对类别列给频数与占比。
4. **对比与趋势**：按关键维度分组（地区、时间、渠道等）做对比；有时间列时看趋势与环比/同比。
5. **异常与相关性**：标出显著偏离的离群点；对关心的两列估算相关（并提醒相关≠因果）。
6. **结论优先**：

```
# 数据分析：<文件名/主题>
## 核心结论
- <最重要的 2–3 条发现>

## 关键数字
- <指标>：<值>（口径：<说明>）

## 异常与注意
- <离群点 / 数据质量问题>

## 可视化建议
- 用 <图表类型> 展示 <某关系>，横轴 X、纵轴 Y
```

## 注意事项
- 结论要带口径（「按周汇总」「剔除测试数据」），否则数字无意义。
- 样本量很小时，避免过度推断；明确标注「样本有限」。
- 若数据过大无法全量处理，先抽样并说明抽样方式。
