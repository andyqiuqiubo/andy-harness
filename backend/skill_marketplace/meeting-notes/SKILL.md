# 会议纪要提取

把非结构化的讨论内容（会议转写、群聊记录、口头沟通摘要）整理成清晰、可执行的会议纪要。

## 何时使用
- 用户提供了一段会议录音的文字转写、聊天记录或讨论草稿，需要结构化输出。
- 用户说「把这段整理成纪要」「提炼决策和待办」。

## 步骤
1. **通读全文**，识别这是一场会议/讨论，还是多场混杂。若混杂，按主题或时间分段。
2. **抽取要素**：
   - 会议主题 / 背景
   - 参与人（如可识别）
   - 关键讨论点
   - 形成的决策（明确结论）
   - 争议或未决事项
   - 行动项（Action Items）：谁、做什么、何时完成
3. **结构化输出**，严格使用以下格式：

```
# 会议纪要：<主题>
日期：<若文中可推断，否则写「未注明」>
参与人：<列表，未知则写「未注明」>

## 讨论要点
- …

## 决策
- …

## 待办（Action Items）
| 事项 | 负责人 | 截止时间 | 状态 |
|------|--------|----------|------|
| …    | …      | …        | 待开始 |

## 未决事项
- …
```

4. **核对**：行动项必须来自原文，不要编造负责人或时间；缺失信息时标注「待确认」而非臆测。
5. 用**用户提问的语言**输出纪要（中文提问→中文纪要）。

## 注意事项
- 不夸大、不添加原文没有的结论。
- 若原文信息不足，明确标注缺失，而不是猜测填充。
