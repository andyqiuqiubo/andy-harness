## 0. 结论先行

1. **调研报告方案整体正确、可用，但需要 4 处修正 + 2 处补项**，否则直接照抄会在工程上踩坑（详见第 2 节）。

### 3.3 主链路：智谱 CogView-3-Flash（推荐）

- **模型性质**：官方文档「图像生成模型」表中明确标注 **CogView-3-Flash = 免费模型，适合轻量图像创作，支持多分辨率**。
- **接口**：`POST https://open.bigmodel.cn/api/paas/v4/images/generations`（OpenAI 兼容，可直接用 `openai` SDK 改 `base_url`）。
- **支持分辨率**：`1024x1024`、`768x1344`、`864x1152`、`1344x768`、`1152x864`、`1440x720`、`720x1440`。
- **门槛**：bigmodel.cn 注册 → 控制台生成 API Key（按平台要求实名）。免费，**不是限时活动**（官方定位为长期免费引流模型，与 GLM-4.7-Flash 同策略）。
- **并发**：免费模型并发受限，公开来源口径不一（CogView-3-Flash 约 5 并发 / CogVideoX-Flash 约 3 并发 / 部分资料称 1 并发）。**以控制台「速率限制」页为准，工程上按 1–2 并发保守设计 + 串行队列最稳。**
- **水印**：平台「安全管理」中可关闭；请求体亦可用 `watermark_enabled` 控制。

```python
# 智谱 CogView-3-Flash 文生图（主链路）
from openai import OpenAI
import os, requests

client = OpenAI(
    base_url="https://open.bigmodel.cn/api/paas/v4",
    api_key=os.environ["ZHIPU_API_KEY"],
)
resp = client.images.generate(
    model="cogview-3-flash",
    prompt="水墨风格远山如黛，云雾缭绕，留白构图",
    size="1024x1024",
)
url = resp.data[0].url
open("out.png", "wb").write(requests.get(url, timeout=60).content)
```

### 3.4 视频侧：智谱 CogVideoX-Flash（用户指定纳入，官方 OpenAPI 已核实）

- **模型性质**：官方文档「视频生成模型」表中标注 **CogVideoX-Flash = 免费视频生成模型**，输入支持**图像、文本** —— 即 **文生视频（T2V）与图生视频（I2V）一体**，这一点优于报告里 Pavo/Magic Hour 等只能网页操作的免登录方案。
- **接口**：`POST https://open.bigmodel.cn/api/paas/v4/videos/generations`（Bearer key）；**异步任务制**——提交返回 `{id, task_status}`，轮询 `GET /paas/v4/async-result/{id}` 直到 `task_status == "SUCCESS"`，取 `video_result[0].url`（附 `cover_image_url`）下载。
- **CogVideoX-Flash 参数枚举（⚠️ 与 cogvideox-3 不同，勿混用）**：
  - `size`：`720x480`、`1024x1024`、`1280x960`、`960x1280`、`1920x1080`、`1080x1920`、`2048x1080`、`3840x2160`（**没有** `1280x720`/`720x1280`——那是 cogvideox-3 的枚举）；
  - **`duration`（5s/10s）仅 `cogvideox-3` 支持，flash 不支持该参数**；
  - `fps`：`30` 或 `60`（默认 30）；`quality`：`speed`（默认）/`quality`；
  - `with_audio`：AI 音效，默认 false；
  - `watermark_enabled`：默认 true；**传 false 需先在「个人中心-安全管理-去水印管理」签署免责声明**，否则可能被拒；
  - `image_url`：URL 或 Base64 data URI（png/jpeg/jpg，≤5MB）；传图即图生视频。
- **实测（2026-10-22 23:55，真实 key）**：提交即遇 **错误码 1305「该模型当前访问量过大」**，免费档算力排队真实存在——**必须内置退避重试**（代码已实现 1302/1305 等码 4-10 次退避）。
- **优势 vs 报告原方案**：有 API（Pavo 极速无 API）、可脚本化、国内直连、与生图共用同一 key、无需每天抢 3 次额度。
- **代价**：需注册 + 实名；免费档高峰期 1305 过载、出片需分钟级等待（必须异步轮询，不能同步阻塞）。

```python
# 智谱 CogVideoX-Flash 文生/图生视频（异步任务，参数以官方 OpenAPI 为准）
import os, time, requests
ROOT = "https://open.bigmodel.cn/api/paas/v4"
H = {"Authorization": f"Bearer {os.environ['ZHIPU_API_KEY']}"}

def gen_video(prompt, image_url=None, size="1024x1024", fps=30):
    payload = {"model": "cogvideox-flash", "prompt": prompt,
               "size": size, "fps": fps,          # 注意：flash 无 duration 参数
               "quality": "speed", "with_audio": False,
               "watermark_enabled": True}
    if image_url:                                  # 图生视频：传图即切 I2V
        payload["image_url"] = image_url           # URL 或 data:image/png;base64,...
    task_id = requests.post(f"{ROOT}/videos/generations", headers=H,
                            json=payload, timeout=60).json()["id"]
    for _ in range(60):                            # 最多等 10 分钟
        time.sleep(10)
        r = requests.get(f"{ROOT}/async-result/{task_id}", headers=H, timeout=60).json()
        if r.get("task_status") in ("SUCCESS", "success"):
            return (r.get("video_result") or [{}])[0].get("url")
        if r.get("task_status") in ("FAIL", "fail"):
            raise RuntimeError(r)
    raise TimeoutError(task_id)
```

### 3.5 零门槛兜底：Pollinations（按实测参数重写）

必须遵守的三条硬约束（均来自本次实测）：

1. **分辨率 ≤ 768²**（1024² 实测 45s 超时，http 000）；
2. **每 IP ≥ 45 秒一张**（官方 `FREE_LIMIT` 文案），客户端要自己节流，不要靠重试撞运气；
3. **402 与 503 都要当限流处理**，解析 JSON 里的 `Retry after Ns` 做退避；成功响应必须以 `ffd8`（JPEG magic）校验，不能只看 200。

```python
import json, time, urllib.parse, urllib.request

_LAST_CALL = {"ts": 0.0}
MIN_INTERVAL = 46.0            # 官方: 1 image / 45s / IP

def gen_pollinations(prompt, out="out.jpg", size=768, timeout=60, retries=3):
    url = ("https://image.pollinations.ai/prompt/" + urllib.parse.quote(prompt)
           + f"?width={size}&height={size}&nologo=true&seed=42")
    for attempt in range(retries):
        wait = MIN_INTERVAL - (time.time() - _LAST_CALL["ts"])
        if wait > 0:
            time.sleep(wait)
        _LAST_CALL["ts"] = time.time()
        try:
            with urllib.request.urlopen(url, timeout=timeout) as r:
                data = r.read()
            if data[:2] == b"\xff\xd8":          # 真 JPEG 才算成功
                open(out, "wb").write(data)
                return out
        except urllib.error.HTTPError as e:      # 402 FREE_LIMIT / 503 过载
            body = e.read().decode("utf-8", "ignore")
            try:
                msg = json.loads(body)["error"]["message"]
            except Exception:
                msg = body[:120]
            print(f"[pollinations] {e.code}: {msg}")
        except Exception as e:                   # 超时(1024² 常见)也归入退避
            print(f"[pollinations] error: {e}")
        time.sleep(5 * (attempt + 1))
    return None
```

### 3.6 统一降级链（推荐实现契约）

```python
PROVIDERS = ["zhipu_cogview3flash", "cloudflare_flux", "pollinations"]

def generate_image(prompt, size="1024x1024"):
    errors = []
    for name in PROVIDERS:
        try:
            return _DISPATCH[name](prompt, size)
        except Exception as e:
            errors.append(f"{name}: {e}")
            continue                    # 逐级降级
    raise RuntimeError("all providers failed -> " + " | ".join(errors))
```

**关键工程约定**：

- 每个 provider 必须返回**本地文件路径或 bytes**，并对返回值做**格式校验**（JPEG `ffd8` / PNG `89504e47`），避免把错误 JSON 当图片存盘；
- **终态判断不能只看 HTTP 状态码**：Pollinations 402/503、kavel.ai 200+`wall:true` 都要解析业务字段；
- 全部失败时抛出可诊断的聚合错误，便于运维定位是哪个上游挂了；
- 免费档一律**串行 + 节流**，禁止并发打满触发平台风控。
