# 免费 AI 生成式模型服务调研报告（文生图 / 图生图 / 文生视频 / 图生视频）

- **调研日期**：2026-10-22（信息窗口：2026-06 至 2026-10，免费政策变动频繁，使用前请以官网实时条款为准）
- **核心筛选条件**：① 无需注册账号、无需登录即可调用或使用；② 不依赖积分、点数或充值付费体系
- **覆盖能力**：文生图（T2I）、图生图（I2I）、文生视频（T2V）、图生视频（I2V）
- **附加维度**：访问方式、调用限制（频率 / 分辨率 / 时长 / 水印）、可集成性（API 及门槛）、优劣对比、国内网络可达性

## 0. 结论摘要（TL;DR）

1. **文生图是唯一存在"完全零门槛"且可规模化调用的能力**：`image.pollinations.ai` 旧端点（GET URL 直接返回 JPEG，无 key 无账号，匿名档实测 **1 张/45 秒/IP**，且须用 ≤768² 分辨率，1024² 实测超时）是当前全网唯一经过多方实测的免注册出图 API；Perchance / Raphael / Mage.space / AIGAZOU / freegen.app 等浏览器工具亦为零门槛，但均无 API。
2. **图生图的零门槛选项次之**：Dezgo（网页免注册，含 img2img/inpainting）、freegen.app（图片参考）、AIGAZOU（图片编辑）、kavel.ai（匿名头 + credits 钱包）可用；完整参数控制仍需本地 SD WebUI / ComfyUI。
3. **视频类（T2V/I2V）零门槛极度稀缺，但 2026-09 起出现真实可用的免登录选项**：Pavo 极速模式（app.pavo-ai.cn，无需注册、每天 3 次、5 秒、480p、带音频、约 10 秒出片，国内直连）与 Magic Hour（T2V/I2V 各 3 次/天、3 秒、480p、带音频、免费档带水印）为目前最可靠的免登录视频入口；Hugging Face ZeroGPU 公开空间（未登录 2 分钟 GPU/天）为第三选择。
4. **若接受"一次免费注册"（无卡、无积分付费陷阱），最接近全模态零成本的方案是 Agnes AI API**：OpenAI 兼容，文本/图像/视频 Flash 模型 $0，视频限时免费（约 1 RPM，最长 18 秒、720p/1080p、音画同步、无水印）；其姊妹产品 Pavo 网页端免登录可用。权衡：需邮箱注册、频率受限、免费视频定价为限时促销、官方保留调整权（2026-09 免费限额已减半一次）。
5. **唯一"真正无限、无水印、可商用、无账号"的路径是本地自托管开源权重**：ComfyUI + Wan 2.2（Apache 2.0，T2V/I2V 一体 5B 版 FP8 仅需 6-8GB 显存）+ FLUX.1 [schnell] / Z-Image Turbo（图，Apache 2.0）。代价是硬件门槛（NVIDIA 8GB 起步、16GB 舒适、24GB 上 720p）与一下午的搭建时间。
6. **聚合类"免登录无限"站点（如 videoplus.ai）信息自相矛盾且 WHOIS 隐藏，不建议作为生产依赖**，详见第 6 节风险提示。

## 1. "零门槛"定义与判定口径

本报告将市面宣传的"免费"分为四档，全文按此口径判定：

| 档位 | 定义 | 本文判定 |
|------|------|----------|
| A. 完全零门槛 | 免注册、免登录、免 API key、无积分/点数/充值体系 | ✅ 符合用户核心条件 |
| B. 准零门槛 | 开发者/使用者侧零 key（成本转嫁终端用户免费账号），或需一次免费注册但无卡无积分陷阱 | ⚠️ 最接近替代，需说明权衡 |
| C. 免费额度制 | 需注册，有每日/每月免费额度，超额需付费 | ❌ 不符合，列为对照 |
| D. 本地自托管 | 一次性硬件投入，之后零边际成本、零账号 | ✅ 特殊达标（有硬件门槛） |

## 2. 文生图（T2I）

### 2.1 A 档：完全零门槛

#### 2.1.1 Pollinations.ai（旧端点 image.pollinations.ai）— 唯一免注册出图 API

- **访问方式**：纯 HTTP GET，返回 JPEG 二进制。浏览器地址栏、`<img>` 标签、curl、任意 HTTP 客户端均可：
  ```bash
  curl -o out.jpg "https://image.pollinations.ai/prompt/a%20cozy%20cabin%20at%20dusk?width=1024&height=1024&nologo=true&seed=42"
  ```
- **可用参数**：`width` / `height`（默认 1024×1024）、`seed`（同 prompt+seed 结果确定性可复现）、`nologo=true`（去标识）、`enhance=true`（提示词自动增强）、`model`（匿名档已静默固定）。
- **调用限制（2026-10-22 本机实测修正 ⚠️）**：匿名档模型为 **Sana**（非 FLUX，`GET /models` 实测返回 `["sana"]`；显式传 `model=flux` 不报错但静默降级）；官方限流文案为 **"Free limit reached: 1 image every 45 seconds per IP"**（即 **45 秒/IP**，非 40 秒）；限流返回 **HTTP 402 `FREE_LIMIT` 的结构化 JSON**（非空的，`error.message` 内含 `Retry after Ns`），**同时存在 HTTP 503 `SERVICE_UNAVAILABLE`**（"The Classic API is at its limit right now"）——**两种码都必须当限流处理**；**1024² 实测 45 秒超时无响应（http 000）**，可用分辨率须降到 **≤768²**（512² 实测 200 + 真 JPEG）；成功响应应以 JPEG magic `ffd8` 校验，不能只看状态码。
- **可集成性**：★★★★★ 零门槛最强。无 key、无 SDK、无后端，Markdown/HTML 可直接嵌入 URL。同域还有 `text.pollinations.ai`（匿名单模型 GPT-OSS 20B）。
- **重要变化**：新版 API `gen.pollinations.ai` 已改为**必须 API key**（Pollen 积分付费，$1≈1 Pollen）；目前仅旧端点 `image.pollinations.ai` / `text.pollinations.ai` 仍匿名开放。项目整体 MIT 开源，可自建网关。
- **优劣**：零门槛、可复现、MIT 可自托管；但无 SLA、匿名档模型档次已降为 Sana、频率低（约 90 张/小时上限）、官方随时可能效仿新端点关停匿名访问。定位：原型、演示、占位图、Discord/Telegram 机器人。

## 4. 文生视频（T2V）

### 4.1 A 档：完全零门槛（稀缺，2026-09 起出现真实可用者）

#### 4.1.1 Pavo 极速模式（app.pavo-ai.cn）— 免登录视频首选，国内直连

- **出品方**：Agnes AI（新加坡 Sapiens Technology，全球 AI Lab 排名前十；旗下另有全模态免费 API，见 5.1）。
- **访问方式**：浏览器打开 `https://app.pavo-ai.cn` → 点 Start Creating，**无登录弹窗、无手机号**，输入提示词或上传首帧图即可生成。免登录产物存于浏览器缓存，**清理缓存即丢失，需立即下载**。
- **限制（2026-09-07 多家媒体实测）**：**每天 3 次免费**；单条 **5 秒**；**480p**；**自带音频**（雨声/脚步/环境音实测逼真）；**约 10 秒出片**（实测 9.49s，基于 fal 后训练的 MiniMax H3 Max 极速模型）。
- **注册后加码**（可选，仍免费）：Agnes Video 2.5 Flash 模型免费（720p、4-12s、最多 5 图+音频输入），每日领 200 积分（2 积分/秒 ≈ 100 秒/天）。
- **可集成性**：❌ 极速模式无 API（网页 only）。API 走 Agnes AI Platform（见 5.1）。
- **优劣**：免登录 + 带音频 + 10 秒级速度 + 国内直连，四者兼得全网仅此一家；代价是每天仅 3 次、480p、无水印信息未明示、无 API、缓存易失。

#### 4.1.2 Magic Hour（magichour.ai）

- **访问方式**：浏览器打开即用，无账号无信用卡。
- **限制**：**T2V 与 I2V 各 3 次/天**；单条 **3 秒**；**480p**；带音频；**免费导出带水印**；免费档仅限个人非商用（付费 $12/月起去水印 + 商用）。
- **可集成性**：有 REST API（Python/Node/Go/Rust SDK），但面向付费；免费档无 API。
- **优劣**：T2V+I2V+视频编辑三入口均免登录；额度少、时长短、水印 + 商用限制明确。

#### 4.1.3 Hugging Face ZeroGPU 公开空间

- **访问方式**：浏览器打开任意公开 ZeroGPU Space（如 Wan 2.2 / LTX 演示）。
- **限制**：**未登录 2 分钟 GPU/天**（免费账号 5 分钟/天，PRO 40 分钟）；24h 滚动重置；硬件为半张 RTX Pro 6000 Blackwell（48GB）。
- **可集成性**：Gradio UI 可直接用；API 需账号与 Space owner 授权。
- **优劣**：可白嫖前沿开源视频模型（Wan 2.2、LTX-2.5）；GPU 分钟数极少、排队、每次默认 60s GPU 窗口。

#### 4.1.4 videoplus.ai — ⚠️ 高风险，仅作备忘

宣称"免注册、无水印、无限"、集成 Kling 2.6 / Vidu Q3 Pro / Veo / Sora 等旗舰模型、FLUX.2 Klein 每日 8 次。但：① WHOIS 隐藏、Scamadviser 虽评"likely safe"但无实质背书；② 另一评测称其免费档实为 **100 credits/月**且快速耗尽，与"无限"宣传矛盾；③ "免费提供 Kling/Veo 旗舰模型"不符合各厂商业逻辑（这些模型官方均需付费账号），存在中间人转售、试用接口或滥用的可能。**不建议上传敏感图片，不建议作为生产依赖。**

## 9. 风险、合规与使用须知

1. **无 SLA 与政策漂移**：零门槛服务随时可能关停或转收费。Pollinations 是活样本——新版 `gen.pollinations.ai` 已强制 key+Pollen 积分，仅旧端点仍匿名；Agnes AI 免费视频定价明示为"限时促销"且 2026-09 已减半一次免费限额。**生产环境必须预留降级链**（如 Pollinations → Cloudflare → 本地）。
2. **商用授权**：A 档网页工具多数仅限个人使用（Magic Hour 免费档明确禁商用；Craiyon 仅个人）；可商用的干净路径是 **Apache 2.0 权重本地部署**（FLUX.1 [schnell]、Wan 2.2、Z-Image Turbo、FLUX.2 [klein]）或明确授权的服务（Dezgo 声称图片归用户、CreativeML Open Rail；AIGAZOU 声称可商用——建议以实时条款复核为准）。
3. **隐私**：匿名生成的图片通常**无历史记录、缓存清理即失**（Pavo 明示）；部分平台可能将匿名上传内容公开或用于改进服务。敏感图片、人脸、客户素材走本地或注册制服务。
4. **聚合站风险**：宣称"免登录无限 + 旗舰模型"（videoplus.ai 类）与商业逻辑相悖，存在转售/试用接口/滥用可能；WHOIS 隐藏、宣传自相矛盾（"无限" vs "100 credits/月"）。仅可用于非敏感试验。
5. **内容审查差异**：云端服务（尤其国内平台与国际大厂）有内容过滤；本地无过滤但**合规责任自负**（人物肖像、版权 IP、当地法律）。
6. **网络可达性（中国大陆）**：国内直连——Pavo、魔搭 ModelScope、硅基流动、腾讯混元、可灵/即梦/海螺/Vidu；一般可达但偶有波动——Cloudflare API、Hugging Face、Pollinations；需代理——Google AI Studio/Gemini、OpenAI 系。
7. **限额判定坑**：kavel.ai 额度耗尽返回 **HTTP 200 + `wall:true`**（非错误码）；Pollinations 限额返回 **HTTP 402 + 空 JSON**。对接时必须校验业务终态，不能只看 status code。

```python
import urllib.parse, urllib.request, time
def gen(prompt, path="out.jpg"):
    url = f"https://image.pollinations.ai/prompt/{urllib.parse.quote(prompt)}?width=1024&height=1024&nologo=true"
    for attempt in range(5):            # 402/空响应 → 退避重试
        try:
            with urllib.request.urlopen(url, timeout=120) as r:
                data = r.read()
                if data[:2] == b"\xff\xd8":
                    open(path, "wb").write(data); return True
        except Exception:
            pass
        time.sleep(15 * (attempt + 1))   # 匿名档约 1 张/40s
    return False
```
